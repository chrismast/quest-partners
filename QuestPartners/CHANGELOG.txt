# Quest Partners 0.6.0 - first Release

This promotes the tested Test9 addon to the first Release. Addon behaviour,
sync protocol and saved settings are unchanged; the version and release
documentation now identify 0.6.0.

- Compare party quests and individual objective progress for up to five players.
- Search quest titles, items and creatures; star a persistent Working on shortlist.
- Use All/Shared filters, region grouping, collapsed summaries and sorting.
- Adjust opacity, colours, font size, bar height and quest spacing.
- Show optional level-difficulty badges, behind-player highlights and local
  objective-completion / everyone-ready notifications. Sound is off by default.

Targets WoW Forever 1.60.1 / interface 16001 only. Every participating player
needs Quest Partners; using the same version is recommended. Raids and other
WoW clients are not supported. Test9 Alpha is retained as the previous build.

This is a release of the existing tested feature set, not a claim of coverage
for every client/addon combination. Please include the addon version, client
build, reproduction steps and /questpartners status in problem reports.


# 0.6.0-test9 — first public Alpha candidate

This file packages the current Test9 code for a first public Alpha. It adds no
runtime changes over the private Test9 build.

- Quest difficulty badges, title/objective search and a persistent Working on shortlist.
- Party quest and objective comparisons for up to five players on WoW Forever.
- All/Shared filters, region groups, collapsed summaries and individual bars.
- Adjustable appearance, stable sorting, behind-player highlights and pins.
- Local objective-completion bubbles and optional everyone-ready notifications.
- Reusable visible rows, changed-only work and paced party communication.
- Bounded message handling and safer shared UI/command behaviour.

Targets Forever 1.60.1 / interface 16001. Participating players need the addon;
using the same version is recommended. Sound is off by default.

117 automated tests passed for Test9. Automated evidence does not establish
every live client/addon combination. Please report reproducible Alpha issues
with the client build, addon version and sync diagnostics.
